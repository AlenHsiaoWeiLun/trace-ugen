Problem definition → our task

Flag worker–vehicle near misses.
Answer what happened, with the footage.

The problem. Construction accounted for 42% of Taiwan's workplace deaths in 2025. Sites already run cameras, but no one watches them all day: near misses between workers and machines go unnoticed, and after an incident, finding the right seconds takes hours.

USERSSafety officers and site managers · first pilot: WanZe
INPUTExisting site cameras · files today, live streams in Stage II
FLAGSA worker overlapping a vehicle in the image, and for how long
OUTPUTClip, duration, reason → a person confirms or dismisses → audit log
ASK“Why was the 07:58 alert flagged?” → an answer that cites the clip
RUNS ONDetection on the 2.5 W UGen300 · memory and Q&A on the host
MEASURED BYAt WanZe in Stage II: near misses caught, false alerts per hour, time to find evidence, FPS and power
